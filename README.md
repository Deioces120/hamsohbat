# هم‌صحبت

یک اتاق گفت‌وگوی گروهی فارسی برای اعضای دعوت‌شده. سایت رابط کاربری را می‌دهد و سرور Node.js ورود کاربران و پیام‌های مشترک را مدیریت می‌کند. ثبت‌نام عمومی وجود ندارد؛ مدیر حساب‌ها را از خط فرمان می‌سازد.

## نیازمندی و اجرای محلی

- Node.js نسخهٔ 22.5 یا بالاتر
- اجرای پروژه از همین پوشه:

```powershell
npm start
```

سپس در مرورگر همان دستگاه به `http://127.0.0.1:3000` برو.

## ساخت حساب‌های دعوتی

در یک پنجرهٔ PowerShell دیگر، از پوشهٔ پروژه اجرا کن:

```powershell
node admin.js add sara
node admin.js add arman
```

اگر رمز را تعیین نکنی، رمز تصادفی ساخته می‌شود و فقط یک‌بار در خروجی همان فرمان نمایش داده می‌شود؛ آن را جداگانه و امن به کاربر بده. برای تعیین رمز خودت:

```powershell
node admin.js add sara "یک-رمز-تصادفی-و-طولانی"
```

دستورهای مدیریتی دیگر:

```powershell
node admin.js list
node admin.js password sara
node admin.js disable sara
node admin.js enable sara
```

ثبت‌نام عمومی بسته است. سقف اولیه ۲۰ حساب است؛ برای تغییرش، متغیر محیطی `MAX_USERS` را روی سرور تنظیم کن. غیرفعال‌کردن حساب، ورود بعدی را می‌بندد و نشست‌های فعال را باطل می‌کند.

## استفاده از گوشی‌ها و دستگاه‌های جدا

برای آزمایش روی یک شبکهٔ Wi-Fi مشترک، سرور را روی رایانه‌ای اجرا کن که همه به آن دسترسی دارند. در PowerShell:

```powershell
$env:HOST = "0.0.0.0"
npm start
```

روی گوشی، نشانی IP رایانه را با پورت `3000` باز کن؛ مثلاً `http://192.168.1.25:3000`. اجازهٔ دسترسی برنامه از فایروال شبکهٔ خصوصی ویندوز ممکن است لازم باشد.

برای استفاده از اینترنت و شبکه‌های متفاوت، پروژه باید روی یک میزبان Node.js با نشانی عمومی و HTTPS اجرا شود. پوشهٔ `data/` را روی فضای ذخیره‌سازی پایدار همان میزبان نگه دار؛ پایگاه‌دادهٔ حساب‌ها و گفت‌وگوها در `data/chat.sqlite` قرار می‌گیرد. روی میزبان، حساب‌های نهایی را با رمزهای تازه از طریق `node admin.js add ...` بساز. حساب‌های نمونهٔ دستگاه توسعه را برای استفادهٔ عمومی به کار نبر.

## ذخیره‌سازی و حریم خصوصی

- پیام‌ها برای اعضای واردشدهٔ اتاق مشترک نمایش داده می‌شوند و روی سرور ذخیره می‌شوند.
- این نسخه رمزنگاری سرتاسری ندارد؛ مدیر سرور به فایل پایگاه‌داده دسترسی دارد. برای پیام خصوصی یا اطلاعات حساس طراحی نشده است.
- رمز عبور کاربران به شکل متن ساده ذخیره نمی‌شود؛ نشست با کوکی `HttpOnly` نگه‌داری می‌شود.
- برای استفادهٔ عمومی، HTTPS را در میزبان یا پراکسی معکوس فعال کن و `NODE_ENV=production` بگذار.
- `data/` در Git نادیده گرفته شده تا رمزها، نشست‌ها و پیام‌های کاربران وارد مخزن نشوند.
- پوستهٔ PWA قابل نصب است؛ برای چت و ورود، دستگاه باید به سرور متصل باشد.
